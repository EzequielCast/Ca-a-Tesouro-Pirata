# Ca-a-Tesouro-Pirata
Caça ao Tesouro Pirata em Kotlin (terminal). Escolha 1 para navegar digitando X e Y (0 a 20), 2 para ler o mapa ou 3 para desistir. O programa calcula a distância até o tesouro, o clima muda o custo da viagem e a bússola dá dicas. Null safety trata entradas vazias, letras e trechos rasgados do mapa
